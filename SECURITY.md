# Security policy

Please report security-sensitive problems through GitHub's private
vulnerability reporting feature after it is enabled for the repository. Do
not attach a live Karabiner configuration, logs, recordings, or other personal
data to a public issue.

Windows Keyboard for Mac intentionally refuses to install when it detects another
system-level modifier mapping. It also limits generated rules to explicitly
enrolled physical keyboards and verifies the active profile after each
transaction.

Unsigned preview releases are provided as-is. Verify the accompanying SHA-256
checksum before opening an archive. A signed and notarized application is
planned for a later product-quality release.
