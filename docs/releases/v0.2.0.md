# Windows Keyboard for Mac v0.2.0

This is the first generic GitHub preview of Windows Keyboard for Mac.

## Highlights

- Familiar Windows-style shortcuts on a selected physical Windows keyboard.
- Per-device isolation that leaves built-in, Apple, virtual, and unconfirmed
  keyboards unchanged.
- Automatic discovery of each Mac's input-source shortcut for `Win+Space`.
- Transactional installation with backup, live readback, rollback,
  diagnostics, and uninstall.
- No app-specific shortcut defaults, personal keyboard identifiers, telemetry,
  or network requests.

## Requirements

- macOS 15 or newer
- Karabiner-Elements 15 or newer
- A connected physical Windows keyboard
- Default macOS Modifier Keys and no active `hidutil UserKeyMapping`

## Install

Download the release ZIP and matching `.sha256` file, verify the checksum, then
follow `docs/quick-start.md`.

## Known limitations

- The preview `.command` bundle is not Apple-signed or notarized.
- Karabiner-Elements must be installed separately and its Apple permissions
  must be approved manually.
- Physical shortcut smoke testing is required on each newly enrolled keyboard.
