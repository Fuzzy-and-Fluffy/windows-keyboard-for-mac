# Windows Keyboard for Mac v0.2.1

This patch release fixes Finder filename editing.

## Fixes

- Backspace deletes the previous character while renaming a file instead of
  navigating to the previous Finder location.
- Enter accepts the filename edit instead of opening the selected item.
- Delete, Shift+Delete, Ctrl+X, Ctrl+V, and F2 also stop invoking file actions
  while a Finder text field is focused.
- Finder file actions fail closed when the focused UI element cannot be
  identified.

## Requirements

- macOS 15 or newer
- Karabiner-Elements 16 or newer
- A connected physical Windows keyboard
- Default macOS Modifier Keys and no active `hidutil UserKeyMapping`

Karabiner-Elements 16 requires Accessibility permission for focused UI element
detection. Complete its macOS permission prompts before installing this
release.

## Known limitations

- The preview `.command` bundle is not Apple-signed or notarized.
- Karabiner-Elements must be installed separately and its Apple permissions
  must be approved manually.
- Physical shortcut smoke testing is required on each newly enrolled keyboard.
