# Windows Keyboard for Mac v0.4.2

This unsigned preview fixes Spotlight shortcuts that produced no visible
search UI on macOS Tahoe.

## Spotlight

A quick Windows-key tap, Win+R, and Win+S now emit the native Apple Spotlight
key event. All three intentionally open the same Spotlight search interface,
providing familiar equivalents for Windows Start, Run, and Search.

Both left and right Windows-key tap rules are updated. The 250 ms tap timeout,
lazy modifier behavior, device isolation, remote-app exclusions, and Win+Space
input-source action remain unchanged. Spotlight output does not repeat when a
key is held.

Existing device-scoped users can run `install.command` from the new ZIP to
update their selected-keyboard profile. This ZIP does not update an imported
community rule; community users should follow the update linked from
[issue #7](https://github.com/Fuzzy-and-Fluffy/windows-keyboard-for-mac/issues/7).

## Verification

On macOS 26.2 with Karabiner-Elements 16.1.0 and a physical Microsoft Windows
keyboard, the previous rules produced no visible Spotlight for Windows-key
tap, Win+R, or Win+S in Finder. We replaced the four Spotlight output objects
in the active profile, and the operator subsequently confirmed that all three
shortcuts opened Spotlight. The post-test environment reported Karabiner
16.3.0, so this was not a controlled comparison on a single Karabiner version.
The new output also passed CLI lint on 16.1.0 before the retest. The local
Spotlight system shortcuts remained disabled.
Both left/right definitions have regression coverage; a separate physical
right-Windows-key test was not recorded.

Build, regression tests, public-content audit, Karabiner CLI lint, live profile
readback, and local doctor checks passed. The regression gate was also verified
to reject the old launch action, shadowing rules, extra disabling conditions,
and missing remote exclusions. These checks do not replace a full clean-account
or separate-Mac release smoke test, which has not been performed for this
preview.

## Requirements and assets

- macOS 15 or newer and Karabiner-Elements 16 or newer
- `Windows-Keyboard-for-Mac-v0.4.2.zip`
- `Windows-Keyboard-for-Mac-v0.4.2.zip.sha256`

The optional VS Code terminal bindings from v0.4.1 remain included. This
package is not Apple-signed or notarized; Karabiner must be installed separately.
