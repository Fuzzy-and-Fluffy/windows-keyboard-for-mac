# Windows Keyboard for Mac v0.3.1

This patch release makes the visual shortcut walkthrough easier to read and
adds a user-controlled interactive version.

## Highlights

- The README GIF now runs for 49 seconds instead of 16 seconds.
- Introductory and closing scenes remain visible for seven seconds; shortcut-
  dense scenes remain visible for eight or nine seconds.
- The new interactive demo has visible Previous, Next, Play/Pause, and direct
  slide-picker controls.
- Left and Right Arrow keys navigate between scenes, and the Play/Pause button
  controls automatic rotation.
- Starting manual navigation pauses automatic rotation so the demo cannot move
  away while a visitor is reading.
- Autoplay starts disabled when the visitor prefers reduced motion.
- Every scene has descriptive alternative text, manual changes are announced
  to screen readers, and all controls are keyboard accessible.

## Keyboard behavior

This release does not change the Karabiner profile or any keyboard mapping.
It contains the same mapping behavior as v0.3.0.

## Safety and privacy

- Only keyboards explicitly selected during installation are enrolled.
- The MacBook built-in keyboard, Apple keyboards, virtual keyboards, and
  unselected external keyboards remain unchanged.
- The package contains no telemetry, account requirement, personal app
  settings, pre-enrolled keyboard identifiers, or live Karabiner configuration.

## Requirements

- macOS 15 or newer
- Karabiner-Elements 16 or newer
- A connected physical Windows keyboard
- Default macOS Modifier Keys and no active `hidutil UserKeyMapping`

## Known limitations

- The preview `.command` bundle is not Apple-signed or notarized.
- Karabiner-Elements must be installed separately and its Apple permissions
  must be approved manually.
- Animated GIFs cannot provide their own controls. Use the linked interactive
  demo to pause or navigate manually.
