# Windows Keyboard for Mac v0.4.0

This release makes Home and End context-aware and introduces a simpler official
catalog installation path alongside the existing device-scoped installer.

## Highlights

- Home and End use Windows-style line and document navigation while a text
  control has focus.
- Outside text controls, Home and End pass through unchanged for native page
  navigation in browsers, web views, terminals, and other apps.
- Empty or unavailable accessibility focus information now fails closed instead
  of invoking an unrelated application menu command.
- The README now distinguishes the all-keyboards community catalog edition from
  the selected-keyboard GitHub edition.
- The community edition is available through the official Karabiner-Elements
  community rules catalog.

## Choose an edition

- **Community catalog edition:** one predefined rule that applies to every
  keyboard, including a MacBook keyboard.
- **Device-scoped GitHub edition:** converts only the external Windows keyboard
  models selected during setup and includes discovery, backup, verification,
  diagnostics, rollback, and uninstall support.

The catalog edition does not include the device-scoped installer's keyboard
selection and recovery workflow.

## Safety and privacy

- Only keyboards explicitly selected during the downloadable edition's setup
  are enrolled in that edition.
- The package contains no telemetry, account requirement, personal app
  settings, pre-enrolled keyboard identifiers, or live Karabiner configuration.
- Terminal Control sequences and remote desktop/virtual machine modifier
  passthrough remain protected.

## Requirements

- macOS 15 or newer
- Karabiner-Elements 16 or newer
- Default macOS Modifier Keys and no active `hidutil UserKeyMapping`
- A connected physical Windows keyboard for the device-scoped edition

## Known limitations

- The downloadable `.command` bundle is not Apple-signed or notarized.
- Karabiner-Elements must be installed separately and its Apple permissions
  must be approved manually.
- The community catalog edition applies to all keyboards; choose the GitHub
  edition when built-in or Apple keyboards should keep native shortcuts.
